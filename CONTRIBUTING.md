# Contributing

Bug reports and suggestions are welcome: please open an issue. For a problem reading a PDF, say what
was read wrongly and, if you can share it, attach the PDF. Remove anything private first. For a
crash, attach `%APPDATA%\PDFDesk\logs\pdfdesk.log`, which you can find through **Help > Open Log
Folder**.

Please open an issue before writing code. Code contributions aren't being accepted yet, because
they would need a contributor agreement that doesn't exist yet.

If you find a security problem, please use GitHub's private reporting on the repository's Security
tab rather than a public issue, if it's available there.
